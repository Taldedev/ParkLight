# ParkLight

> Light the way to your spot.

A smart parking lot management system with shortest-path-based slot allocation.
Built as the final project for the Advanced Java course at HIT.

## Repository layout

- `AlgorithmModule/` — Shortest path algorithm library (Part A). Packaged as a JAR
  and consumed by the application module.
- `ParkLightProject/` — The ParkLight server-side application (Part B).
  *(to be added)*

## Tech stack

- Java 8 (`JavaSE-1.8`)
- JUnit 4 for unit tests
- No external frameworks (no Spring, no Maven). Plain `javac` + `jar`.
